Carregando o painel.

Todos os números são simulados por uma fórmula. Nenhum vem de conta real de anúncios.

Período

Campanhas no painel

Dados simulados. Passe o cursor, toque, ou foque e use as setas.

ROAS por campanha

Reais de receita para cada real gasto. Abaixo de 1, a campanha gasta mais do que traz. Dados simulados.

CPA por campanha

Quanto custa, em média, cada venda. Quanto menor, melhor. Dados simulados.

Campanha por campanha

Clique no título de uma coluna para ordenar. Dados simulados.

Calculadora de verba

Mude os números para estimar o que uma verba mensal poderia trazer. É uma conta de cabeça em forma de página, não uma promessa de resultado.

Como isto funciona

O que acontece aqui

Uma fórmula gera 180 dias de números por campanha, sempre iguais para a mesma data. O painel soma o período escolhido e calcula CPC (gasto dividido por cliques), CPA (gasto dividido por vendas) e ROAS (receita dividida por gasto). Os gráficos são desenhados em SVG, sem biblioteca. Suas escolhas ficam guardadas neste navegador.

O que dá para adaptar

Campanhas, métricas, períodos, gráficos, faixas de alerta, marca do cliente e a fórmula da calculadora.

O que a versão real precisaria a mais

Conexão autorizada com as plataformas de anúncios e com o sistema de vendas, um servidor que busque e guarde os dados, login por cliente e uma regra combinada de como cada venda é atribuída a uma campanha.
