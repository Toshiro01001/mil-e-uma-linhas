      parede-de-desejos/site com IA e chave protegida
      

        
navegador ---> worker ---> IA
              [ a chave da API
                mora aqui, nunca
                no navegador ]
desejo: "..."
preço: gerado na hora

        

          
Parede de Desejos

          
Cada desejo escrito recebe um preço criado por um modelo de IA. O site é estático e a chamada passa por um Cloudflare Worker, então a chave da API nunca aparece no navegador. O uso exige uma chave de acesso.

          
JavaScript, Cloudflare Workers, API de IA
